# 竖式列加法 Transformer 的训练与离线评估

状态：Done（训练结束；最终检查点 `adder-final.pt`，部署产物为 ONNX，见 [[adder-onnx-cpu-inference]]）
最后更新：2026-10-16

## 背景与问题

`human_files/adder_transformer.md` 定义了购物车结账所用的神经加法器：Transformer 只负责固定尺寸 \(10\times 8\) 竖式矩阵的列加法，乘法展开、分批归并、高位累加与金额格式化全部由 Python 完成。当前仓库只有设计文档，没有可用模型权重。本规格覆盖“训练并离线评估该模型”，使后续结账切片有可加载的模型。

## 目标与非目标

### 目标

- 按设计文档实现模型结构、数据生成、进位监督损失和训练循环，训练环境为本机 RTX 2080 Ti 上的 PyTorch CUDA。
- 训练结束后保存检查点，并输出测试集与边界集的离线指标。
- 所有训练代码可在 CPU 上跑通单元测试；GPU 仅用于正式训练。

### 非目标

- 不实现 `tree_sum`、表达式解析、乘法展开、金额格式化或结账接口（留给后续切片）。
- 不接入 FastAPI、前端或数据库。
- 不做模型结构搜索；超参数采用设计文档默认值。
- 不提交检查点文件到 Git。

## 用户与领域规则

- 输入矩阵 \(X\in\{0..9\}^{10\times 8}\)，列为最低有效位优先；最高列 \(X_{r,7}=0\)，行数不足 10 补零行。
- 输出 8 位数字 \(Y\) 及每列的下一进位预测；真值由 Python 整数加法计算，不由模型或另一套神经网络生成。
- 金额语义不在本切片：模型只处理整数行，单位无关。

## 主流程

1. 数据生成器按 `adder_transformer.md` §6.1 随机生成 1–10 个加数（0..9,999,999）。每批 10% 为边界样本：半数为“整块同值”（10 行均为 0/1/9/9,999,999，使列和可达 90），半数为逐行从这四个值取样且倾向满 10 行（§6.2 的边界课程）。
2. 模型内部由行求和得到列和 \(\sigma_i\in\{0..90\}\)，经列嵌入与列位置嵌入后进入 2 层、4 头、\(d=64\) 的因果 Transformer（列 mask：第 \(i\) 列只看 \(0..i\) 列）。
3. 每列两个头：数字 logits（10 类）与下一进位 logits（10 类）。
4. 损失 \(\mathcal{L}=\mathrm{CE}_{\text{digit}}+\lambda\,\mathrm{CE}_{\text{carry}}\)，\(\lambda=1\)。
5. AdamW，学习率 \(3\times10^{-4}\)，批次 256，训练 \(10^5\) 步，固定随机种子。
6. 训练结束保存检查点，并在固定种子的测试集（10^4）与边界集上评估。

## 边界与失败场景

| 场景 | 预期行为 |
|---|---|
| 单行 `9999999` 或全 9 列 | 输出正确，进位链完整 |
| 10 行全 `9999999` 或全 `9`（列和 90） | 输出正确；该类别必须出现在训练分布中 |
| 10 行全 `9999999` | 输出 `99999990`，不溢出 8 位 |
| 全零矩阵或仅零行 | 输出全 0，进位全 0 |
| 输入最高列非 0 | 推理入口拒绝（数据层断言），不进入模型 |
| 行数超过 10 或非法数字 | 数据层拒绝 |
| 行置换 | 输出完全相同（列和对行置换不变，由结构保证并测试） |

## 验收标准

- [x] Given 随机 \(10\times8\) 矩阵，When 计算真值，Then 数字与进位与整数加法 `sum(v)` 的十进制展开一致。
- [x] Given 任意矩阵及其行置换，When 前向推理，Then 数字与进位 logits 完全相同。
- [x] Given 最高列非零的输入，When 构造训练/推理样本，Then 抛出错误。
- [x] Given 训练完成的检查点，When 在固定测试集上评估，Then 整和准确率 ≥ 99.9%（阈值经 Q-010 确认）。实测 99.97%。
- [x] Given 边界集（全 9、10 行最大和、全零、单行），When 评估，Then 整和准确率 100%。实测 10/10。
- [x] Given 训练脚本，When 以相同种子重复运行 CPU 小规模训练，Then 损失序列一致（可复现）。
- [x] Given 边界采样，When 抽取样本，Then 出现列和为 90 的整块同值样本（训练分布覆盖最大列和）。

每条验收标准至少映射一个测试；测试文件意图块用 `@spec [[adder-transformer-column-addition-training]]` 回链。

## 训练记录

- 运行 1（`backend/checkpoints/adder-run1-boundary-gap/`，未纳入后续结论）：仅使用 10% 逐行边界样本。测试集整和准确率 99.94%，边界集 8/10；失败两例均为列和 90 的整块同值样本（训练分布中几乎不出现），据此新增“整块同值”边界模式。
- 运行 2（`backend/checkpoints/adder-run2-killed-at-64k/`）：加入整块同值边界；约 6.4 万步时被 shell 中止杀死，无最终结论（脚本暂不支持断点续训）。
- 运行 3（`backend/checkpoints/adder/`，正式检查点 `adder-final.pt`）：同运行 2 配置，完整 10 万步，约 25 分钟（RTX 2080 Ti，fp32）。
  - 测试集（10^4，固定种子）：逐位 99.996%，进位 100%，整和 99.97%。
  - 边界集（10 例）：10/10 通过。
  - ONNX 导出校验（20,000 条随机样本）：数字与进位 argmax 100% 一致，最大 logit 差 1.9e-5，整和 99.96%（`backend/checkpoints/adder-onnx-export.log`）。
- 训练结束（2026-10-16，Q-010）：不再继续训练。`adder-final.pt` 为最终检查点；后续推理仅使用导出的 ONNX 模型。
