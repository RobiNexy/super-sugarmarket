# 老板后台：订单、库存与商品维护

状态：Implemented
最后更新：2026-10-17

## 背景与问题

老板需要查看待送货订单，送货并当面点清后在后台完成订单，同时维护商品、价格和库存。后台只在本机演示，不做认证。

## 目标与非目标

### 目标

- 登录页提供可爱的登录体验，不做凭据校验。
- 查看订单列表（默认显示待送货订单），包括房间号、商品明细、成交金额、档位和时间。
- 手动完成订单：扣减该订单中每个商品的库存，并将状态改为“已完成”。
- 维护商品：新增、编辑名称、分类、描述、简单 Emoji 或组合 Emoji 插画、单价（元）、库存、是否展示。
- 组合 Emoji 编辑器需支持图层的添加、移除、排序、位置、尺寸、旋转、横纵缩放/倾斜、变换原点、半幅裁切与实时整体预览；详细格式见 [[cute-ui-copy-and-motion]]。

### 非目标

- 不做认证、权限、多账户或操作日志。
- 不做订单取消、退货、退款。页面上用可爱文案说明退货请下楼找老板。
- 不做报表与统计。

## 用户与领域规则

- 默认账户名“老板”，只做展示，不作为登录校验依据。
- 密码不回填到输入框。登录页在输入框下方展示“密码提示：123223”，用户自行输入。任意输入均可进入后台（Q-003）。
- 登录状态仅保存在 sessionStorage，只用于避免刷新后回到登录页，不构成安全边界。
- 完成订单时：若某商品库存 < 订单数量，拒绝完成并提示“库存不够啦”，订单保持待送货。
- 完成订单在同一事务中执行，保证库存扣减与状态变更同时成功或同时失败。
- 商品单价上限 ¥99,999.99（即 9,999,999 分）；超过时拒绝保存。单价最少 ¥0.00。
- 停用商品（`is_active = 0`）不出现在顾客目录中，但仍可在后台查看与编辑。

## 主流程

### 登录

1. 打开后台，显示登录卡片：账户名“老板”（已填入）、密码输入框（空）、密码提示。
2. 老板输入任意密码，点击进入，播放进入动效。
3. 进入订单页。

### 订单处理

1. 订单页默认展示“待送货”订单，按创建时间升序。
2. 老板送货、当面点清后，点击“完成订单”，弹出确认（可爱文案）。
3. 确认后扣减库存、状态改为“已完成”，列表移除该订单。
4. 库存不够时保持待送货，提示补货。

### 商品维护

1. 商品页列出全部商品（包括停用商品），支持新增与编辑。
2. 保存时后端校验：名称非空，分类非空，价格 0 ≤ 元 ≤ 99999.99 且最多两位小数，库存 ≥ 0 整数。
3. 保存成功后目录页在下次加载时反映变更。

## 边界与失败场景

| 场景 | 预期行为 |
|---|---|
| 登录时输入为空 | 允许进入（不做凭据校验） |
| 完成不存在的订单 | 404，提示订单不存在 |
| 完成已完成的订单 | 409，不重复扣减 |
| 完成时库存不足 | 409 `INSUFFICIENT_STOCK`，订单保持待送货 |
| 保存单价超过上限或超过两位小数 | 422，不保存 |
| 保存库存为负数 | 422，不保存 |
| 停用商品后仍有待送货订单 | 订单保留，可正常完成（库存仍按订单扣减） |
| 顾客询问退货 | 页面文案：请下楼找老板 |

## 验收标准

- [ ] Given 后台登录页，When 页面加载，Then 账户名已填为“老板”，密码输入框为空，并显示“密码提示：123223”，且密码值不出现在 DOM 的 value 中。
- [ ] Given 密码输入框，When 输入或聚焦，Then 播放动效（不影响输入）。
- [ ] Given 输入任意密码，When 点击进入，Then 进入订单页。
- [ ] Given 待送货订单，When 老板完成订单，Then 库存按订单数量扣减，状态为已完成，且两者在同一事务中完成。
- [ ] Given 库存不足，When 老板完成订单，Then 返回 409，库存与状态均未变化。
- [ ] Given 已完成订单，When 再次完成，Then 返回 409，库存不再扣减。
- [ ] Given 保存单价 `12.345` 元，When 提交，Then 返回 422。
- [ ] Given 编辑商品的 Emoji 组合，When 调整图层位置/变形/裁切，Then 预览呈现一个组合后的整体造型，保存后目录页按相同方式显示。
- [ ] Given 停用商品，When 顾客查看目录，Then 不显示；在后台仍可见。
- [ ] Given 顾客询问退货，When 查看订单页，Then 显示“请下楼找老板”文案。

每条验收标准至少映射一个测试；测试文件意图块用 `@spec [[admin-backoffice]]` 回链。
