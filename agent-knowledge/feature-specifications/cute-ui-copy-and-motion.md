# 可爱文案与动效规范

状态：Implemented（结账/后台/Emoji 组合插画及编辑器已实现，文案动效按此规格落地）
最后更新：2026-10-17

## 背景与问题

Sugarmarket 的产品语气是可爱、轻松、略带调侃。所有界面文案必须带 emoji 或颜文字，不允许出现干巴巴的提示。视觉沿用 `human_files/template.html`，具体组件可在此基础上推广。

## 视觉基线

- 配色（来自模板）：`#FFB400` 黄、`#FF7AC6` 粉、`#4D96FF` 蓝、`#FF5E5B` 红、`#C34DE0` 紫、`#00C2A8` 青；浅底 `#FFF7E8`、`#FFE9F2`、`#E8F7FF`；深字 `#2B2140`。
- 字体：`"Comic Sans MS","Chalkboard SE","楷体",cursive,sans-serif`。
- 卡片：圆角、粗描边或偏移阴影 `5px 5px 0 rgba(0,0,0,.25)`，允许轻微旋转（约 ±3°）。
- 价格显示为元，两位小数，例如 `¥5.20`；金额字符串由服务端提供。
- 页面背景使用奶油渐层、细蜡笔横纹、低对比度圆点、固定位置的小 Emoji 涂鸦和两三笔 SVG 蜡笔曲线；装饰不遮挡交互内容，尊重减少动效设置。
- 标题采用糖果色贴纸牌、深色描边和短文字阴影。分类药丸各用专属 Emoji 与浅底色：饮品 🥤、零食 🍿、速食泡面 🍜、日用品 🧻、全部 🌈；不重复使用同一个图标。
- 商品标签纸不采用统一整齐模板：按商品 ID 生成稳定但看似随机的倾斜、大小、位置、透明度；少数商品名成为更大、歪斜的贴纸，少数额外带“老板推荐/今日好物”等小贴章。
- 桌面商品网格每行 5 张卡；视口变窄时依次减为 4、3、2、1 列。
- “全部”分类下在目录载入时打乱商品顺序并保持本次页面会话稳定，使不同类别交错呈现。

## 商品 Emoji 组合图案

商品 Emoji 是商品插画，不是把几个 Emoji 字符并排输出。组合图案应允许素材发生缩放、旋转、倾斜、裁切/遮罩、覆盖、折叠与互相嵌合，并以一个新造型、一个整体图案显示。

### 组合描述格式

商品可使用普通 `emoji`，也可提供 `emoji_art` 组合描述。组合描述用固定 100×100 画布和分层素材表达，示例：

```json
{
  "version": 1,
  "layers": [
    { "emoji": "🍓", "x": 50, "y": 53, "size": 58, "rotate": -12, "scale_x": 1.15, "scale_y": 0.9, "z": 1 },
    { "emoji": "🍃", "x": 63, "y": 23, "size": 31, "rotate": 38, "scale_x": 0.8, "scale_y": 1.2, "z": 2, "clip": "ellipse" },
    { "emoji": "✨", "x": 78, "y": 68, "size": 20, "rotate": 12, "scale_x": 1, "scale_y": 0.7, "z": 3 }
  ]
}
```

- `version`：格式版本，目前为 `1`。
- `layers`：按 `z` 升序叠放；至少 2 层才构成组合图案，最多 12 层。
- `emoji`：该层的单个 Emoji 素材。
- `x`、`y`：画布百分比坐标，0–100。
- `size`：字号，画布宽度的百分比，1–100。
- `rotate`：旋转角度，−180° 至 180°。
- `scale_x`、`scale_y`：横纵缩放，0.2–2.0；允许不等比缩放来形成变形、折叠感。
- `skew_x`、`skew_y`：可选倾斜角，−30° 至 30°；默认 0。
- `origin_x`、`origin_y`：可选变换原点百分比，0–100，默认 50；用于让图层围绕边缘旋转，模拟折页/包裹。
- `z`：图层顺序，0–20。
- `clip`：可选 `circle`、`ellipse`、`rounded`、`left_half`、`right_half`、`top_half`、`bottom_half`，用于裁切素材；同一 Emoji 可拆成多个裁切图层并分别变换，组合出折叠/包裹关系。
- `x`、`y`、`size`、`rotate`、`scale_x`、`scale_y`、`skew_x`、`skew_y`、`origin_x`、`origin_y` 必须为有限数值且满足各自范围；不接受字符串、CSS 表达式或 NaN/Infinity。
- 图层允许超出画布边缘，画布容器裁切溢出部分。组合整体需清晰、可辨识，不能只是互不相交地并排摆放。
- 不允许远程图像、任意 HTML、任意 CSS 或用户提供的 SVG；组件只解释上述白名单参数。

### 渲染与管理

- 使用一个正方形 `EmojiArt` 画布容器，将各图层作为绝对定位的 Emoji glyph 绘制，并应用缩放、旋转与裁切；容器本身作为单个商品视觉整体参与布局。
- `emoji_art` 存在时只渲染组合画布；为空时回退到普通 `emoji`；两者都为空时不显示图案，保留商品文字信息。
- 组合图案整体标注 `aria-label` 为商品名称；内部 Emoji 图层对辅助技术隐藏，避免逐层朗读。
- 后台商品编辑器支持预览和调整图层位置、大小、旋转、横纵变形、顺序及裁切；提供至少一个组合素材编辑入口。保存前即时预览最终整体效果。
- 种子商品内容应优先为适合组合的商品设计整体图案，使用重叠、嵌合或裁切构成新轮廓；不可把“🥤🍓✨”当成完成的组合设计。

## 动效基线

沿用模板动效，不引入新的动效库：

| 名称 | 用途 | 参数 |
|---|---|---|
| `cardin` | 卡片进入 | `scale(.6) rotate(10deg)` → 正常，0.5s，`cubic-bezier(.34,1.56,.64,1)` |
| `jelly` | 按钮悬停/点击 | 缩放 1 → 1.15 → 0.95 → 1，0.5s |
| `wob` | 提示卡轻摇 | 旋转 −3° ↔ 2°，3.5s 循环 |
| `charin` | 标题字符逐个弹入 | 0.3s 弹性 |
| `draw` | 选中药丸的描边绘制 | 0.4s |

新增组件动效：

- **输入框聚焦**：边框颜色在两种糖果色间切换，聚焦时 emoji 小幅弹跳（`jelly`）。
- **输入框输入**：每输入一个字符，输入框底部一个小 emoji 弹出并消失（约 0.3s）。
- **登录成功**：卡片向上飞出并旋转 360°，随后进入订单页（约 0.6s）。
- **提示标签**：从右上角以 `cardin` 弹出，停留 4 秒后淡出；可手动关闭。
- **加入购物车**：商品卡按钮 `jelly`，购物车数字 `charin`。
- **老板的红色塑料袋**：购物袋固定悬浮在视口右下角，红色手绘袋身加购物袋 Emoji 和商品数量；点击商品加入时，商品 Emoji 从卡片位置沿弧线缩小旋转飞入袋口，数量徽章弹跳。
- 尊重系统减少动效设置（`prefers-reduced-motion`）：关闭上述动效，保留颜色变化。

## 文案规则

- 每条界面文案必须包含至少一个 emoji 或颜文字。
- 语气：可爱、轻松、略带自嘲，不指责顾客。
- 错误文案也要可爱，但必须让顾客知道下一步怎么做。

## 边界与失败场景

| 场景 | 预期行为 |
|---|---|
| 文案缺少 emoji 或颜文字 | 视为缺陷，修复后方可合并 |
| `prefers-reduced-motion` 开启 | 不播放位移与旋转动效，保留颜色与文字 |
| 同时出现多个标签 | 只显示一个档位标签；库存提示可与之同时出现 |

## 验收标准

- [ ] Given 任一界面文案表中的键，When 渲染，Then 文案包含至少一个 emoji 或颜文字。
- [ ] Given 第二档结账，When 下单成功页渲染，Then 只显示 `tier2_wild` 标签。
- [ ] Given Q-011 结账，When 渲染，Then 只显示 `zero_compare` 标签，不显示 `tier2_wild`。
- [ ] Given 第三档结账，When 渲染，Then 只显示 `tier3_free` 标签。
- [ ] Given 商品含两个或更多 Emoji 图层，When 商品卡渲染，Then 图层按变形与叠放参数组合为单个整体图案，不以横排 Emoji 字符替代。
- [ ] Given 商品目录首次载入，When 顾客看到分类和货架，Then 分类次序与图标符合本规格，“全部”在最后，默认选中饮品，商品卡每行最多 5 张且标签纸存在稳定的随机差异。
- [ ] Given 顾客加入商品，When 商品 Emoji 飞入固定悬浮红袋，Then 动画结束后徽章数量更新；减少动效模式下无位移动画但数量仍更新。
- [ ] Given `emoji_art` 含无效版本、越界坐标或非法变换值，When API 写入商品，Then 返回 422 并指出字段错误，不保存无效组合描述。
- [ ] Given 商品组合图案，When 辅助技术读取商品卡，Then 将组合图案作为单个商品插画并以商品名称朗读，不逐层朗读 Emoji。
- [ ] Given 登录页，When 聚焦密码输入框并输入字符，Then 出现输入动效且不影响输入值。
- [ ] Given 系统开启减少动效，When 渲染任一组件，Then 不出现位移或旋转动效。

每条验收标准至少映射一个测试或视觉检查记录；测试文件意图块用 `@spec [[cute-ui-copy-and-motion]]` 回链。
