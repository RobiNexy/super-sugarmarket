# 领域术语表

记录项目内有特定含义、容易混淆或需要统一翻译的术语。

| 术语 | 定义 | 英文/代码标识 | 易混淆项 | 示例 |
|---|---|---|---|---|
| Sugarmarket / 苏格小卖铺 | 项目所复刻和重新设计的小型网上小卖铺，灵感来自苏格公寓楼下的小超市。 | Sugarmarket | 项目名称，不代表真实经营中的线上商店 | 本项目演示 Sugarmarket 商品浏览与下单 |
| 商品 | 可单独浏览、加入购物车和销售的目录项；不同包装/规格各自作为独立商品，不建变体。 | Product | 商品分类、规格变体 | 一瓶矿泉水与一箱矿泉水是两个商品 |
| 商品目录 | 可供商店展示和销售的商品及其文字描述、Emoji 展示标记等信息集合；首版不要求真实商品图片。 | Catalog | 原始数据库备份 | 商品数据可用“🥤”作为视觉标记 |
| 库存 | 某一商品当前记录的数量；顾客下单时不扣减，老板送达并手动完成订单时扣减。 | Inventory / Stock | 购物车中的预选数量 | 购物车数量与库存记录不是同一个概念 |
| 购物车 | 顾客结账前暂存所选商品及数量的集合。 | Cart | 已创建的订单 | 加入购物车本身不代表创建订单 |
| 结账 | 将购物车内容交给计算与下单流程，并生成模拟订单；不执行真实支付。 | Checkout | 支付 | 结账成功可产生订单，但不表示已收款 |
| Transformer 结账计算 | Transformer 输出的整数分金额是最终成交价；即使偏差很大也采用该结果。Python/TypeScript 的精确加法仅计算差异，不纠正或阻止下单；相对差异超出 ±50% 时提示，Transformer 返回 null 则免单。 | Transformer Checkout Calculator | 测试 oracle、成交金额 | 模型返回 ¥12.34、对照为 ¥5.20 时仍按模型结果结账；返回 null 时显示免单文案 |
| 模拟订单 | 本机演示结账后创建、等待老板送货并手动完成的订单记录，不含真实支付结果。 | Demo Order | 已支付订单 | 老板送达后在后台将订单标记完成 |
| 后台 | 首版供老板管理商品和库存、查看并手动完成订单的本机界面；不做身份认证。 | Back Office / Admin | 顾客 storefront | 老板送货完成后手动完成订单 |
| 退货 | 首版不提供应用内退货能力；如需退货，顾客线下下楼联系老板。 | Return / Refund | 后台订单完成 | “退货请下楼找老板本人唠嗑～” |
| 老板演示信息 | 后台页面可展示的固定演示账户名“老板”和密码“123223”；不进行身份验证或凭据校验。 | Demo Owner Credentials | 真实账户、安全凭据 | 演示文案显示“老板 / 123223” |
| 商品规格 | 同类商品的容量、包装等可售区分；本项目中不建规格变体，而拆成独立商品。 | Product Variant | 商品目录项 | 500 ml 矿泉水和整箱矿泉水分别建商品 |

## 记录规则

- 一个术语只保留一个规范写法；新增同义词时说明是否可互换。
- 定义应能帮助新会话在缺少上下文时正确使用该术语。
- 术语意义发生变化时，同步检查规格、ADR 与代码意图块中的引用。
