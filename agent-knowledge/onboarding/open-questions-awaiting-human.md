### Q-005：Transformer 结果与对照加法的权威关系
- 状态：Resolved
- 背景：神经网络输出可能与常规精确加法不同，需确定实际订单金额采用哪一个结果。
- 选项：使用 Transformer 结果；用精确加法回退/纠正；或阻止差异过大的订单。
- Agent 建议及理由：让成交价始终来自 Transformer，另算差值供演示和诊断，确保模型确实参与结账。
- 人类裁决：只要 Transformer 产出有效金额，就无论结果差距多大都按该金额结账。Python 或 TypeScript 加法只计算差异，不得回退、纠正、替代或阻止结账；差距很大时可显示文案“嘿嘿，有时候神经网络就是很神经”。
- 日期：2026-10-14

### Q-006：诊断差异的“很离谱”阈值
- 状态：Resolved
- 背景：需将“大差异”的趣味提示定义为可实现和可测试的条件。
- 选项：按整数分绝对差值；按相对比例；或同时使用两者。
- Agent 建议及理由：使用相对差异能适应不同购物车金额；零参考金额单独处理。
- 人类裁决：相对差异达到正负 50% 边界之外时触发提示，即 `(Transformer 金额 - 对照金额) / 对照金额` 大于 50% 或小于 -50%；恰好 ±50% 不触发。对照金额为 0 而 Transformer 金额非 0 时触发。提示文案：“嘿嘿，有时候神经网络就是很神经”。
- 日期：2026-10-14
