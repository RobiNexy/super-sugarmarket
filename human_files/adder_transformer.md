# 基于竖式矩阵与因果 Transformer 的购物车金额加法器

## 摘要

设计一种用于购物车总价计算的神经加法系统。系统不直接端到端计算任意表达式，而是由 Python 完成表达式解析、金额转整数分、乘法展开为循环加法、分批归并与最终格式化；Transformer 只负责固定尺寸的竖式列加法：\(10\) 行、\(8\) 位列宽、最低有效位优先。为抑制溢出，输入矩阵最高列恒为 \(0\)，因此每行有效数字为 \(7\) 位，最大输入为

\[
09999999_{10}=9{,}999{,}999.
\]

每批最多 \(10\) 行，故单批总和最大为

\[
10\times 9{,}999{,}999=99{,}999{,}990,
\]

仍可由 \(8\) 位十进制数表示。模型采用行置换不变编码、列方向因果注意力、显式进位监督与数字分类头。该设计以强归纳偏置把“十以内加法”封装进 Transformer，而把乘法、调度、归并和高位累加全部交给 Python。其工程定位接近黑色幽默：牛刀杀鸡，且刀必须被重新锻造成算盘。

**关键词：** 竖式加法；归纳偏置；因果 Transformer；进位状态机；购物车总价；神经符号混合

---

## 1 引言

购物车总价计算可写为

\[
\text{Total}=\sum_{j=1}^{n} p_j q_j,
\]

其中 \(p_j\) 为商品单价，\(q_j\) 为数量。若金额以“分”为整数存储，则问题化为整数加乘。经典算法为 \(O(1)\) 到 \(O(n)\) 的符号运算，完全不需要神经网络。本文故意反其道而行：用 Transformer 计算固定尺寸的列加法，并由 Python 处理其余全部逻辑。

目标不是追求最优工程，而是研究一个受约束问题：如何为“序列模型做加法”注入接近全加器的归纳偏置，同时保留 Transformer 骨架。核心观察是：两个整数相加不是一般序列到序列映射，而是一个有限状态机。其状态只有进位。两数加法中，进位状态为 \(\{0,1\}\)；十行加法中，进位状态为 \(\{0,\dots,9\}\)。普通 Transformer 若没有该偏置，会退化为查表模型，训练集内准确，长进位链上不可靠。

本文采用竖式矩阵输入：

\[
5.20\times 4+13.14
\]

转为整数分并展开为循环加法：

\[
520,520,520,520,1314.
\]

补零至 \(8\) 位并右对齐，得到矩阵：

\[
\begin{matrix}
00000520\\
00000520\\
00000520\\
00000520\\
00001314\\
00000000\\
\vdots\\
00000000
\end{matrix}
\]

模型只做这件事：给定 \(10\times 8\) 矩阵，输出 \(8\) 位总和。

## 2 问题形式化

### 2.1 金额表示

所有金额以整数分表示。两位小数金额 \(x\) 元转为

\[
x_{\text{cents}}=\operatorname{round}(100x).
\]

例如：

\[
5.20\to 520,\qquad 13.14\to 1314.
\]

最终输出再除以 \(100\) 并格式化两位小数。

### 2.2 竖式矩阵

定义输入矩阵

\[
X\in\{0,1,\dots,9\}^{10\times 8}.
\]

列索引约定为最低有效位优先：

\[
i=0,1,\dots,7,
\]

其中 \(i=0\) 为最低位，\(i=7\) 为最高位。行索引 \(r=1,\dots,10\)。

每行数值为

\[
v_r=\sum_{i=0}^{7} X_{r,i}10^i.
\]

输入约束为最高列恒为 \(0\)：

\[
X_{r,7}=0,\qquad r=1,\dots,10.
\]

因此每行有效数字为 \(7\) 位，最大值为

\[
v_r\le 09999999_{10}=9{,}999{,}999.
\]

行数不足 \(10\) 时补全零行。行顺序可任意置换。

### 2.3 输出

模型输出

\[
Y\in\{0,1,\dots,9\}^{8},
\]

表示总和

\[
S=\sum_{i=0}^{7} Y_i10^i.
\]

单批总和满足

\[
S=\sum_{r=1}^{10} v_r\le 10\times 9{,}999{,}999=99{,}999{,}990.
\]

因此 \(8\) 位输出足够，且最高位可用于进位缓冲。

### 2.4 进位递推

令进位

\[
c_i\in\{0,1,\dots,9\}
\]

为第 \(i\) 列向第 \(i+1\) 列的进位。初始化

\[
c_0=0.
\]

第 \(i\) 列总和为

\[
t_i=c_i+\sum_{r=1}^{10} X_{r,i}.
\]

输出数字为

\[
s_i=t_i\bmod 10,
\]

下一进位为

\[
c_{i+1}=\left\lfloor \frac{t_i}{10}\right\rfloor.
\]

最终输出 \(Y_i=s_i\)。

**进位界证明。**
归纳：\(c_0=0\le 9\)。若 \(c_i\le 9\)，则

\[
t_i\le 9+10\times 9=99,
\]

故

\[
c_{i+1}=\lfloor t_i/10\rfloor\le 9.
\]

又因 \(X_{r,7}=0\)，最高列

\[
t_7=c_7\le 9,
\]

所以

\[
s_7=c_7,\qquad c_8=0.
\]

故 \(8\) 位输出无溢出。

### 2.5 行置换不变性

每列进位只依赖列和

\[
\sigma_i=\sum_{r=1}^{10} X_{r,i},
\]

不依赖行顺序。因此加法对行置换不变。

## 3 系统总览

系统分为两层：

1. **符号层：Python 预处理与后处理**
   - 解析用户表达式；
   - 金额转整数分；
   - 乘法展开为循环加法行；
   - 补零、右对齐、分批；
   - 调用神经网络；
   - 归并部分和；
   - 最终转元并格式化。

2. **神经层：固定尺寸竖式加法器**
   - 输入 \(10\times 8\) 矩阵；
   - 输出 \(8\) 位总和；
   - 核心是列加法状态机。

数据流：

\[
\text{表达式}
\to \text{整数分行}
\to \text{竖式矩阵}
\to \text{Transformer 加法器}
\to \text{部分和}
\to \text{树形归并}
\to \text{总价}.
\]

## 4 归纳偏置与模型架构

### 4.1 列和充分统计量

由于

\[
t_i=c_i+\sum_{r=1}^{10} X_{r,i},
\]

第 \(i\) 列的具体分布不重要，只有列和

\[
\sigma_i=\sum_{r=1}^{10} X_{r,i}\in\{0,\dots,90\}
\]

重要。因此编码阶段直接计算列和，天然实现行置换不变性。

### 4.2 输入表示

对每列 \(i\)，构造 token：

\[
h_i^{(0)}=E_\sigma(\sigma_i)+P_i,
\]

其中

\[
E_\sigma:\{0,\dots,90\}\to\mathbb{R}^d
\]

为可学习嵌入，\(P_i\in\mathbb{R}^d\) 为第 \(i\) 列的列位置嵌入。由于列数固定为 \(8\)，可使用可学习绝对列位置。行位置完全不存在。

### 4.3 因果列 Transformer

Transformer 编码器接受列序列

\[
h_0^{(0)},h_1^{(0)},\dots,h_7^{(0)}.
\]

注意力 mask 定义为

\[
M_{ij}=
\begin{cases}
1,& j\le i,\\
0,& j>i.
\end{cases}
\]

含义：第 \(i\) 列只能看到 \(0,\dots,i\) 列，即低位列可以影响高位列，符合进位方向。序列顺序为最低有效位优先。

每层为标准多头自注意力、前馈网络、残差连接与层归一化。列数只有 \(8\)，模型可以非常小，例如

\[
d=64,\quad \text{layers}=2,\quad \text{heads}=4.
\]

### 4.4 输出头与进位监督

第 \(i\) 列隐藏状态 \(h_i\) 经过两个线性头：

\[
o_i^s=W_s h_i+b_s\in\mathbb{R}^{10},
\]

\[
o_i^c=W_c h_i+b_c\in\mathbb{R}^{10}.
\]

\(o_i^s\) 预测输出数字 \(s_i\)，\(o_i^c\) 预测下一进位 \(c_{i+1}\)。

训练损失：

\[
\mathcal{L}
=
\sum_{i=0}^{7}
\mathrm{CE}(o_i^s,s_i^*)
+
\lambda
\sum_{i=0}^{7}
\mathrm{CE}(o_i^c,c_{i+1}^*).
\]

通常取 \(\lambda=1\)。真值由 Python 整数加法计算。

推理时：

\[
\hat{s}_i=\arg\max o_i^s,\qquad
\hat{c}_{i+1}=\arg\max o_i^c.
\]

最终输出 \(Y=(\hat{s}_0,\dots,\hat{s}_7)\)。

### 4.5 可选自回归进位变体

若希望进位传播更显式，可将序列展开为

\[
C_0,S_0,C_1,S_1,\dots,C_7,S_7.
\]

训练时 teacher forcing，推理时逐步反馈进位。该变体更接近全加器状态机，但推理慢。固定 \(8\) 列下，推荐并行因果版本。

## 5 分批归并与树形求和

### 5.1 分批规则

设预处理后得到行列表

\[
R=(v_1,\dots,v_N),
\]

其中每行

\[
0\le v_j\le 9{,}999{,}999.
\]

每批最多取 \(10\) 行。若 \(N\le 10\)，直接调用模型。若 \(N>10\)，每 \(10\) 行一批调用模型。

### 5.2 部分和拆分

每批模型输出

\[
S_k\in[0,99{,}999{,}990].
\]

将其拆分为低 \(7\) 位和高位：

\[
S_k=\operatorname{low}_k+10^7\operatorname{high}_k,
\]

其中

\[
\operatorname{low}_k=S_k\bmod 10^7,\qquad
\operatorname{high}_k=\left\lfloor \frac{S_k}{10^7}\right\rfloor.
\]

因为

\[
S_k\le 99{,}999{,}990,
\]

所以

\[
0\le \operatorname{low}_k\le 9{,}999{,}999,\qquad
0\le \operatorname{high}_k\le 9.
\]

低 \(7\) 位可继续作为下一轮输入行，满足每行最大 \(09999999\) 的约束。高位由 Python 单独累加。

### 5.3 树形归并算法

```python
def tree_sum(rows, model):
    H = 0          # 高位累加器，权重 10^7
    R = rows       # 当前行列表，每行 <= 9_999_999

    while len(R) > 10:
        new_R = []
        for batch in chunks(R, 10):
            X = build_matrix(batch)      # [10, 8]，最高列为 0
            S = model.predict(X)         # [8] 数字，转整数
            low = S % 10**7
            high = S // 10**7
            new_R.append(low)
            H += high
        R = new_R

    # 最后一批
    X = build_matrix(R)
    S = model.predict(X)
    low = S % 10**7
    high = S // 10**7
    H += high

    total = H * 10**7 + low
    return total
```

正确性：

\[
\sum_{v\in R} v
=
\sum_{\text{batches}} (\operatorname{low}_k+10^7\operatorname{high}_k)
=
\sum \operatorname{low}_k+10^7 H.
\]

递归后，低 \(7\) 位和继续相加，高位无损累加。最终结果精确等于原始行总和。

### 5.4 复杂度

设总行数 \(N\)。每轮行数约降为

\[
\left\lceil \frac{N}{10}\right\rceil.
\]

模型前向次数为

\[
O\left(\frac{N}{10}\right).
\]

树高为

\[
O(\log_{10} N).
\]

符号层负责高位累加、归并调度、金额格式化。神经层只处理固定 \(10\times 8\) 加法。

## 6 训练方法

### 6.1 数据生成

随机生成 \(m\in\{1,\dots,10\}\) 个加数。每个加数

\[
v_r\sim \mathcal{U}\{0,1,\dots,9{,}999{,}999\}.
\]

将每个 \(v_r\) 转为 \(8\) 位十进制字符串，最高位补 \(0\)，然后按最低有效位优先排列为列。行数不足 \(10\) 时补全零行。随机打乱行顺序作为增强。

训练样本真值由 Python 精确加法计算，同时提取每列输出数字 \(s_i^*\) 和进位 \(c_{i+1}^*\)。

### 6.2 课程学习

可先训练短进位链，再训练长进位链：

1. 随机均匀数据；
2. 加入 \(9999999+1\)、全 \(9\) 列、多行全 \(9\) 等边界；
3. 加入行置换样本；
4. 加入补零行、单行、全零行。

### 6.3 损失与优化

损失：

\[
\mathcal{L}
=
\mathcal{L}_{\text{digit}}
+
\lambda\mathcal{L}_{\text{carry}}.
\]

优化器：AdamW，学习率 \(3\times10^{-4}\)，批次大小 \(256\)，训练 \(10^5\) 步。由于问题规模小，通常很快收敛。

2. Python 解析为商品、单价、数量。
3. 金额转整数分。
4. 乘法展开为循环加法行。
5. 检查每行是否满足

\[
0\le v_j\le 9{,}999{,}999.

6. 调用 `tree_sum`。
7. 得到整数分总额。
8. 转元：

\[
\text{total\_yuan}=\frac{\text{total\_cents}}{100}.
\]

9. 格式化为两位小数。

## 8 实验设计

### 8.1 数据集

- 训练集：\(10^6\) 个随机 \(10\times 8\) 矩阵。
- 验证集：\(10^4\)。
- 测试集：\(10^4\)。
- 边界测试集：全零、全 \(9\)、长进位链、行置换、单行、十行最大和。

### 8.2 指标

- 逐位准确率；
- 整和准确率；
- 进位准确率；
- 行置换不变性误差；
- 端到端购物车总价准确率。

### 8.3 基线

- 普通 Transformer：MSB-first、无行池化、无进位监督；
- LSTM 序列模型；
- 纯 MLP 按列独立预测；
- Python 精确加法器。

### 8.4 消融

- 去掉行置换不变编码；
- 去掉因果 mask；
- 去掉进位辅助损失；
- 使用回归头替代数字分类；
- 使用 MSB-first 输入；
- 去掉列位置嵌入。

**预期：** 强归纳偏置模型在 \(8\) 位加法上接近精确；普通 Transformer 在训练分布内可能高，但长进位链与行置换上下降。

## 9 边界、失败模式与局限

1. **输入超限。** 单行超过 \(9{,}999{,}999\) 分时，必须拆单或拒绝。
2. **批和拆分。** 每批和可能达到 \(99{,}999{,}990\)，必须拆分为低 \(7\) 位与高位，否则下一轮输入违反约束。
3. **模型误差。** 若某列数字错误，金额至少偏差 \(0.01\) 元。整活系统可接受，生产系统不可接受。
4. **乘法展开行数爆炸。** 数量大时，循环加法行数线性增长。可替换为十进制部分积，但那会削弱黑色幽默。
5. **精确性。** 纯神经端到端不能保证任意长度精确。本设计通过固定尺寸、显式进位监督和 Python 树形归并获得可靠性。
6. **归纳偏置依赖。** 若最高列不为 \(0\)，或行数超过 \(10\)，进位界证明失效。

---

## 10 结论

本文给出一种“用 Transformer 算十以内加法”的完整设计。其核心不是扩大模型，而是压缩问题：

- 行方向：列和编码，行置换不变；
- 列方向：最低有效位优先，因果注意力；
- 数值：数字分类，而非连续回归；
- 状态：显式进位监督；
- 系统：Python 做乘法、分批、归并、高位累加与格式化；
- 神经层：只做固定 \(10\times8\) 竖式加法。

该方案在形式上自洽：输入每行最高位为 \(0\)，有效 \(7\) 位，单批十行总和不超过 \(99{,}999{,}990\)，可由 \(8\) 位输出缓冲。分批归并时，低 \(7\) 位继续送入模型，高位由 Python 无损累加。

最终效果是：杀鸡用牛刀，但牛刀被重新打磨成了算盘。作为整活，它足够严谨；作为工程，它足够荒谬。
